# Image UX (UI-A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Loaded single-slot images (portrait, emblem) hide the upload control and show a hover pencil to replace; any image (portrait, emblem, journal thumbnails) opens full-screen in a global lightbox on click.

**Architecture:** A global `LightboxService` + `LightboxContainer` (mirroring the existing `ConfirmService`/`ConfirmDialog`, mounted once in `MainLayout`) provides click-to-expand for any image. A reusable `ImageSlot` component (`Shared/`) DRYs the portrait and emblem single-image upload slots. Journal thumbnails get a click handler that calls the lightbox. No backend/DTO/storage changes.

**Tech Stack:** Blazor WebAssembly 8, `IStringLocalizer` (resx en + pt-BR), design-system CSS tokens.

**Spec:** `docs/superpowers/specs/2026-08-09-image-ux-design.md`.

## Global Constraints

- **No backend/DTO/storage change** — `IMediaClientService`, `IFileStorageService`, `MediaLimits`, upload methods, and version handling stay exactly as they are; only the markup that renders images changes.
- **Every visible/aria string via `IStringLocalizer<AppStrings>`** in BOTH `AppStrings.resx` (en) and `AppStrings.pt-BR.resx`; keys unaccented ASCII; identical key sets across cultures; pt-BR values carry accents.
- **Design-system tokens only** in CSS (colors/radius/spacing); theme-aware; mirror the existing `.confirm-*` overlay conventions.
- **No JS interop** — the file picker is triggered by a `<label>` wrapping a visually-hidden `<InputFile>` (no `click()` interop); Esc-to-close uses Blazor `@onkeydown`.
- **No bUnit** in the project — verify each task with a clean `dotnet build`; note manual/visual checks in the report.
- **Follow existing patterns** — `LightboxService` mirrors `ConfirmService` (DI-scoped, `Services/`); `LightboxContainer` mirrors `ConfirmDialog` (`Layout/`, mounted in `MainLayout`).

### Task 1: Global lightbox (service + container + CSS + i18n)

**Files:** create `LightboxService.cs`, `LightboxContainer.razor`; modify `Program.cs`, `MainLayout.razor`, `app.css`, both resx.

**Interfaces:**
- Produces: `LightboxService` with `void Show(string dataUri, string? alt = null)`, `void Close()`, `string? CurrentImage { get; }`, `string? CurrentAlt { get; }`, `event Action? OnChange` — consumed by Tasks 2 and 3.

- [ ] **Step 1: LightboxService** — `src/Ruptura.Web/Services/LightboxService.cs`:
```csharp
namespace Ruptura.Web.Services;

// Mirrors ConfirmService: a scoped, event-driven holder for the app-wide image lightbox.
public class LightboxService
{
    public event Action? OnChange;
    public string? CurrentImage { get; private set; }
    public string? CurrentAlt { get; private set; }

    public void Show(string dataUri, string? alt = null)
    {
        CurrentImage = dataUri;
        CurrentAlt = alt;
        OnChange?.Invoke();
    }

    public void Close()
    {
        CurrentImage = null;
        CurrentAlt = null;
        OnChange?.Invoke();
    }
}
```

- [ ] **Step 2: LightboxContainer** — `src/Ruptura.Web/Layout/LightboxContainer.razor` (mirrors `ConfirmDialog.razor` structure + focus handling):
```razor
@using Microsoft.Extensions.Localization
@using Ruptura.Web.Resources
@inject LightboxService Lightbox
@inject IStringLocalizer<AppStrings> L
@implements IDisposable

@if (Lightbox.CurrentImage is { } image)
{
    <div class="lightbox-overlay" @onclick="Lightbox.Close" @onkeydown="OnKeyDown" tabindex="0" @ref="_overlayRef" role="dialog" aria-modal="true">
        <button class="lightbox-close" @onclick="Lightbox.Close" @onclick:stopPropagation="true" aria-label="@L["Common.Close"]">✕</button>
        <img class="lightbox-img" src="@image" alt="@(Lightbox.CurrentAlt ?? string.Empty)" @onclick:stopPropagation="true" />
    </div>
}

@code {
    private ElementReference _overlayRef;
    private bool _wasOpen;

    protected override void OnInitialized() => Lightbox.OnChange += HandleChange;

    private void HandleChange() => InvokeAsync(StateHasChanged);

    private void OnKeyDown(KeyboardEventArgs e)
    {
        if (e.Key == "Escape") Lightbox.Close();
    }

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        var isOpen = Lightbox.CurrentImage is not null;
        if (isOpen && !_wasOpen)
            await _overlayRef.FocusAsync(); // so @onkeydown/Esc works
        _wasOpen = isOpen;
    }

    public void Dispose() => Lightbox.OnChange -= HandleChange;
}
```
(Add `@using Microsoft.AspNetCore.Components.Web` if `KeyboardEventArgs` is not already imported via `_Imports.razor` — check `_Imports.razor` first; it usually is.)

@using Microsoft.AspNetCore.Components.Forms
@using Microsoft.Extensions.Localization
@using Ruptura.Web.Resources
@inject LightboxService Lightbox
@inject IStringLocalizer<AppStrings> L

@if (Uploading)
{
    <div class="image-slot" style="width:@(Size)px;height:@(Size)px">
        <span class="spinner-border spinner-border-sm"></span>
    </div>
}
else if (!string.IsNullOrEmpty(DataUri))
{
    <div class="image-slot image-slot-loaded" style="width:@(Size)px;height:@(Size)px">
        <img class="image-slot-preview" src="@DataUri" alt="@Alt"
             @onclick="() => Lightbox.Show(DataUri!, Alt)" />
        @if (!Disabled)
        {
            <label class="image-slot-edit" @onclick:stopPropagation="true" aria-label="@L["Image.Change"]" title="@L["Image.Change"]">
                <span aria-hidden="true">✎</span>
                <InputFile class="image-slot-file" OnChange="OnFilePicked" accept="image/*" />
            </label>
        }
    </div>
}
else if (!Disabled)
{
    <label class="image-slot image-slot-empty" style="width:@(Size)px;height:@(Size)px">
        <span class="image-slot-empty-icon" aria-hidden="true">＋</span>
        <span class="image-slot-empty-label">@L["Image.Upload"]</span>
        <InputFile class="image-slot-file" OnChange="OnFilePicked" accept="image/*" />
    </label>
}

@code {
    [Parameter] public string? DataUri { get; set; }
    [Parameter] public int Size { get; set; } = 112;
    [Parameter] public bool Uploading { get; set; }
    [Parameter] public bool Disabled { get; set; }
    [Parameter] public string Alt { get; set; } = string.Empty;

}
